# 캐릭터 팩 규격 (v2)

ChatGPT나 다른 이미지 생성기로 만든 캐릭터를 이 규격대로 넣으면, 어떤 캐릭터든 앱 안에서 똑같이 움직인다.

## 원칙: 그림은 팩이, 움직임은 앱이

이미지 생성기는 매번 조금씩 다른 그림을 그린다. 그래서 프레임마다 그린 애니메이션은 덜덜 떨리고 품질이 들쭉날쭉해진다. 이 규격은 역할을 이렇게 나눈다.

- **팩**은 상황별 **포즈 그림**(정지 이미지 1~3장)만 준다.
- **앱**은 점프·흔들기·말랑하게 눌리기·하트 날리기 같은 **움직임과 효과**를 전부 그린다.

그래서 팩을 바꿔도 하트가 날아가는 속도, 맞았을 때 튕기는 정도, 걷는 속도가 모두 같다.

## 폴더 구조

```
characters/<id>/
  manifest.json
  idle.png
  walk-1.png
  walk-2.png
  ...
```

```json
{
  "v": 2,
  "id": "mochi",
  "name": "모찌",
  "author": "만든 사람",
  "speed": 2,
  "fps": 4,
  "hand": [0.72, 0.55],
  "poses": {
    "idle": ["idle.png", "idle-blink.png"],
    "walk": ["walk-1.png", "walk-2.png"],
    "notify": ["notify.png"],
    "heart_send": ["heart-send.png"],
    "heart_hit": ["heart-hit.png"],
    "poke_hit": ["poke-hit.png"],
    "hug": ["hug.png"],
    "status_work": ["work.png"],
    "status_meeting": ["meeting.png"],
    "status_eat": ["eat.png"],
    "status_rest": ["rest.png"],
    "status_busy": ["busy.png"],
    "status_off": ["off.png"]
  }
}
```

| 필드 | 뜻 |
|---|---|
| `v` | 규격 버전. 지금은 `2` |
| `id` | 영문 소문자·숫자·하이픈, 32자 이내. 폴더 이름과 같게 |
| `name` | 화면에 보이는 이름 |
| `speed` | 걷는 속도(틱당 px). 기본 2 |
| `fps` | 한 포즈에 프레임이 여러 장일 때 넘기는 속도. 기본 4 |
| `hand` | 하트가 튀어나오는 손 위치. 이미지 왼쪽 위를 `[0,0]`, 오른쪽 아래를 `[1,1]`로 본 비율 |
| `poses` | 포즈 이름 → 프레임 파일 목록. 1장이면 정지, 2장 이상이면 `fps`로 반복 |

규격에 없는 포즈 이름을 넣어도 오류는 아니고, 앱이 안 쓸 뿐이다.

## 필수 포즈

바탕화면에는 **내 캐릭터와 상대 캐릭터**가 같이 돌아다닌다. 액션을 한 사람의 캐릭터가 "보내는" 포즈를, 다른 캐릭터가 "맞는" 포즈를 취한다. 아래 표의 "언제"는 그 포즈를 취하는 캐릭터 기준이다.

| 포즈 | 언제 나오나 | 그려야 할 모습 | 앱이 더하는 것 |
|---|---|---|---|
| `idle` | 평소, 그리고 다른 포즈가 끝난 뒤 | 정면을 보고 서서 웃는 기본 자세. 2장이면 두 번째를 눈 감은 장면으로 그려서 눈 깜빡임에 쓴다 | 없음 |
| `walk` (2장 이상) | 화면 아래를 걸어 다닐 때 | **오른쪽**을 향해 걷는 자세. 왼발 앞, 오른발 앞 | 위아래 통통 튀기. 왼쪽으로 걸을 땐 좌우 반전 |
| `notify` | 이 캐릭터 주인이 채팅을 보냈을 때 (내 화면에서는 상대 캐릭터만) | 편지 봉투나 말풍선을 두 손으로 들고 신난 얼굴 | 점프, 💬 말풍선 |
| `heart_send` | 이 캐릭터 주인이 하트를 보냈을 때 | 손가락 하트나 두 손 하트를 앞으로 내미는 자세. 손이 `hand` 위치에 오게 | `hand`에서 하트가 화면 쪽으로 날아감 |
| `heart_hit` | 다른 쪽이 하트를 보냈을 때 | 볼이 빨개지고 눈이 하트가 되어 녹아내리는 표정. 몸을 살짝 뒤로 젖힘 | 하트가 날아와 부딪힘, 말랑하게 눌리기 |
| `poke_hit` | 다른 쪽이 콕 찔렀을 때 | 깜짝 놀라 눈이 동그래지고 몸이 움찔한 모습 | 좌우 흔들기, ❗ |
| `hug` | 둘 중 누가 안아줘도 | 두 팔을 크게 벌리고 안기려는 자세, 행복한 눈웃음 | 말랑하게 눌리기, 🤗 |
| `status_work` | 이 캐릭터 주인의 상태가 💻 일하는 중 | 작은 노트북 앞에서 타자 치는 모습 | 상태 아이콘 |
| `status_meeting` | 상태 🗓️ 회의 중 | 서류나 수첩을 들고 진지하게 고개를 끄덕이는 모습. 넥타이나 사원증이 있으면 좋다 | 상태 아이콘 |
| `status_eat` | 상태 🍚 밥 먹는 중 | 밥그릇과 숟가락을 들고 볼이 빵빵하게 먹는 모습 | 상태 아이콘 |
| `status_rest` | 상태 ☕ 쉬는 중 | 머그컵을 두 손으로 감싸고 편하게 쉬는 모습 | 상태 아이콘 |
| `status_busy` | 상태 🔥 바빠요 | 땀방울을 흘리며 서류 더미를 들고 허둥대는 모습 | 상태 아이콘 |
| `status_off` | 상태 🏃 퇴근! | 가방을 메고 손을 흔들며 신나게 뛰어가는 모습 | 상태 아이콘 |

선택 포즈 `poke_send`(이 캐릭터 주인이 콕 찔렀을 때, 검지를 내미는 장난스러운 표정)는 없으면 `idle`로 대신한다. 다른 포즈도 파일을 못 찾으면 `idle`로 대신한다.

상태 포즈는 상태가 바뀔 때 잠깐(약 4초) 보여주고, 그 뒤에는 `idle`/`walk`로 돌아가면서 머리 위 아이콘으로만 표시한다.

## 그림 규칙

검사 스크립트가 **오류**로 막는 것:

- PNG(8bit RGBA, 투명 배경, 인터레이스 없음, 한 변 1024px 이하). SVG는 앱에 들어 있는 기본 캐릭터만 쓴다 (`--svg` 옵션으로 검사)
- 정사각형, 모든 포즈가 같은 크기 (512×512 권장)
- 네 모서리가 투명해야 한다 (흰 배경 그대로 저장한 이미지를 잡아낸다)
- 필수 포즈가 모두 있고, `walk`는 2장 이상. 포즈는 32개, 한 포즈의 프레임은 8장까지

검사 스크립트가 **경고**로 알려주는 것 (위치가 포즈마다 다르면 포즈가 바뀔 때 캐릭터가 순간이동한 것처럼 보인다):

- 발끝(그림의 가장 아래)이 높이의 **92% 근처**(88~97%)에 오게
- 위쪽에 여백을 남긴다 (점프할 때 잘리지 않게)
- 몸 중심이 가로 가운데에 오게

검사하지 않지만 지켜야 하는 것:

- **모든 포즈에서 같은 캐릭터**: 몸 비율, 색, 외곽선 두께, 얼굴 생김새가 같아야 한다
- 2~2.5등신 치비 비율, 굵은 외곽선, 단색 위주. 화면에서는 약 100px로 작게 보이니까 눈·볼처럼 큰 특징 위주로
- 바닥 그림자, 배경, 글자, 테두리는 넣지 않는다 (그림자와 효과는 앱이 그린다)
- 날아가는 하트, 반짝이, 효과선은 그리지 않는다. 포즈에 딸린 소품(노트북, 밥그릇, 머그컵, 편지)만 그린다
- 정면 또는 몸을 살짝 오른쪽으로 튼 자세. `walk`만 완전히 오른쪽을 본다

## ChatGPT로 만드는 순서

1. **기준 이미지 만들기**: 아래 기준 프롬프트로 `idle`을 먼저 만든다. 마음에 들 때까지 이것만 다시 뽑는다.
2. **같은 대화에서 포즈 뽑기**: 기준 이미지를 첨부한 채로 포즈 프롬프트를 하나씩 보낸다. 대화를 새로 열면 캐릭터가 달라지기 쉽다.
3. **투명 배경 확인**: 배경이 흰색으로 나오면 "배경을 투명하게 다시 저장해 줘"라고 요청하거나 배경 제거 도구를 쓴다.
4. **크기 맞추기**: 모든 이미지를 같은 정사각형 크기로 맞춘다. macOS에서는 `sips -z 512 512 *.png`.
5. **manifest.json 작성**: 위 예시를 복사해서 파일 이름만 바꾼다. `hand`는 `heart_send` 그림에서 손이 있는 위치 비율로 적는다.
6. **검사**: `cd app && npm run check:character -- public/characters/<id>`

### 기준 프롬프트

```
데스크톱 위를 돌아다니는 작은 펫 캐릭터를 만들어 줘.
- 캐릭터: [예: 말랑한 분홍 찹쌀떡, 토끼 귀가 달린 아기 고양이]
- 스타일: 2~2.5등신 치비, 둥글고 통통한 실루엣, 굵고 진한 외곽선, 단색 위주의 플랫 컬러, 볼터치
- 자세: 정면을 보고 서서 활짝 웃는 기본 자세
- 구도: 정사각형 캔버스, 캐릭터를 가로 가운데에 두고 발끝이 아래에서 8% 정도 위에 오게. 위쪽은 여백을 넉넉히
- 배경: 완전히 투명한 PNG. 바닥 그림자, 배경, 글자, 테두리, 효과는 넣지 말 것
```

### 포즈 프롬프트

매번 이 문장으로 시작한다.

```
첨부한 캐릭터와 똑같은 캐릭터(같은 비율, 같은 색, 같은 외곽선 두께, 같은 얼굴)로,
같은 구도(정사각형, 가로 가운데, 발끝 높이 동일)와 투명 배경을 유지해서 다음 포즈를 그려 줘.
효과나 날아다니는 하트는 그리지 말고 캐릭터와 소품만 그려 줘.
포즈: <아래 문장>
```

| 포즈 | `<아래 문장>` |
|---|---|
| `idle` 2장째 | 기본 자세 그대로, 눈만 행복하게 감은 모습 |
| `walk-1` | 오른쪽을 보고 걷는 옆모습, 왼발이 앞으로 나와 있음 |
| `walk-2` | 오른쪽을 보고 걷는 옆모습, 오른발이 앞으로 나와 있음 (walk-1과 머리 높이 같게) |
| `notify` | 편지 봉투를 두 손으로 머리 위로 들고 신난 얼굴 |
| `heart_send` | 손가락 하트를 오른쪽 앞으로 쭉 내밀며 윙크 |
| `heart_hit` | 볼이 새빨개지고 눈이 하트가 되어 녹아내리는 표정, 몸을 살짝 뒤로 젖힘 |
| `poke_hit` | 깜짝 놀라 눈이 동그래지고 움찔한 모습, 작은 땀방울 하나 |
| `hug` | 두 팔을 양옆으로 크게 벌리고 안기려는 자세, 눈웃음 |
| `poke_send` (선택) | 검지를 앞으로 쭉 내밀고 장난스럽게 웃는 모습 |
| `status_work` | 작은 노트북 앞에 앉아 열심히 타자 치는 모습 |
| `status_meeting` | 수첩을 들고 사원증을 목에 건 채 진지하게 고개를 끄덕이는 모습 |
| `status_eat` | 밥그릇과 숟가락을 들고 볼이 빵빵하게 먹는 모습 |
| `status_rest` | 김이 나는 머그컵을 두 손으로 감싸고 편하게 쉬는 모습 |
| `status_busy` | 서류 더미를 안고 땀을 흘리며 허둥대는 모습 |
| `status_off` | 가방을 메고 한 손을 흔들며 신나게 뛰어가는 모습 |

## 검사

```
cd app
npm run check:character -- public/characters/<id>
```

오류가 하나라도 있으면 종료 코드 1로 실패한다. 경고만 있으면 통과하지만, 앱에서 포즈가 바뀔 때 캐릭터가 튀어 보일 수 있다.

## 앱에 넣기

채팅 화면 위쪽 **캐릭터** 버튼 → **팩 가져오기**에서 팩 폴더 안의 `manifest.json`과 이미지 파일을 모두 한꺼번에 선택한다.

- 앱이 위와 같은 검사를 한다. 오류가 있으면 아무것도 바뀌지 않고 오류 목록만 보여준다.
- 통과하면 팩을 방 키로 암호화해서 서버에 올리고, 상대 앱이 받아서 **같은 검사를 다시 한 뒤에** 상대 화면의 내 캐릭터로 쓴다. 서버는 내용을 볼 수 없다.
- 팩 전체 크기는 **4MB 이하**여야 한다 (서버는 암호화된 팩을 8MB까지 받는다). 512px PNG 15장이면 보통 이 안에 들어온다.
- **기본 캐릭터로**를 누르면 양쪽 모두 말랑이로 돌아간다.
